## Windows 98 Icons

Icons in the `icons/` folder are original Windows 98 system icons archived and made
available by Alex Meub at https://win98icons.alexmeub.com.

These icons remain the intellectual property of Microsoft Corporation. They are
included here for personal and educational use only. If you intend to use this
template for commercial purposes, you must replace the icons with assets you have
the rights to use commercially.

## MS Sans Serif Font

The `fonts/` folder contains MS Sans Serif converted to web font format (.woff/.woff2),
bundled as part of the 98.css library by Jordan Scales.

MS Sans Serif is the intellectual property of Microsoft Corporation. It is included
here solely for personal and educational use, as a dependency of 98.css, to replicate
the authentic Windows 98 visual style. If you intend to use this template for
commercial purposes, you must replace the font with a freely licensed alternative.

## Mouse Cursors

The SVG files in the `cursors/` folder (`arrow.svg`, `loading.svg`) are original
vector artwork drawn from scratch for this template. They are geometric
approximations of the classic Windows 98 arrow pointer and hourglass, not copies
of Microsoft's cursor files.

They are covered by this template's MIT License and may be reused freely,
including for commercial purposes.
